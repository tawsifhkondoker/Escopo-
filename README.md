# Escopo-
An escape room you can solve in a browser tab. Explore the room, discover clues, solve puzzles, and escape if you can. Built with HTML, CSS, and JavaScript.

# Development
Clone the source code to your device
 git clone https://github.com/tawsifhkondoker/Escopo-.git && cd escopo
Open the project in your code editor.
Start the game by opening index.html in your browser.

# Notes
The game is built using plain HTML, CSS, and JavaScript.
Images used by the game are in /images/.
The main files are index.html, style.css, and script.js.
ESCOPO runs directly in your browser.

# How to Play
Inspect the room,look for clues, find the first lock, solve it, investigate , eventually it will lead to the key that you can use to escape the room.
